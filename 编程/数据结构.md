### 介绍：

#### 常见的数据结构

- 栈：栈是一种特殊的线性表，它只能在一个表的一个固定端进行数据节点的插入和删除操作。
- 队列：队列和栈类似，也是一种特殊的线性表。和栈不同的是，队列只允许在表的一段进行插入操作，而在另一端进行删除操作。
- 数组：数组是一种聚合数据类型，它是将具有相同类型的若干变量有序地组织在一起的集合。
- 链表：链表是一种数据元素按照链式存储结构进行存储的数据结构，这种存储结构具有在物理上存在非连续的特点。
- 树：树是典型的非线性结构，它是包括，2个节点的有穷集合k。
- 图：图是另一种非线性结构。在图结构中，数据节点一般成为顶点，而边是顶点的有序偶对。
- 堆：堆是一种特殊的树形数据结构。一般讨论的对都是二叉堆。
- 散列表：散列表源自散列函数，其思想是如果在结构中存在关键字和T相等的记录，那么必定在F（T）的存储位置可以找到该记录，这样就可以不用进行比较操作而直接取得所查记录。

| 特性     | 描述               | 时间复杂度 |

#### 链表

链表像一列火车，每节车厢都装载着货物，并通过挂钩连接下一节车厢。

##### 基本概念与类型

1. 数据域：存储实际的数据值。
2. 指针域：存储下一个节点在内存中的地址。

链表主要类型：

- 单向链表：节点只指向下一个节点。
- 双向链表：节点同时指向前一个和后一个节点，可以双向遍历。
- 循环链表：尾节点指向头节点，形成一个环。

###### 双向链表代码实现

```C
typedef struct line{
	struct line* prior;//指向直接前趋
	int data;
	struct line* next;//指向直接后继
}line;
```

```C
Line* initline(Line* head)
{
	Line* list = NULL;
	head = (line*)malloc(sizeof(line));//创建链表的一个节点(首元节点)
	head->prior = NULL;
	head->next = NULL;
	head->data = 1;
	list = head;
	for(int i = 2; i <= 5; i++)
	{
		//创建并初始化一个新节点
		Line* body = (Line)malloc(sizeof(line));
		body->prior = NULL;
		body->next = NULL;
		body->data = 1;
		//直接将前趋节点的next指针指向新节点
		list->next = body;
		//新节点指向直接前趋节点
		body->prior = list;
		list = list->next;
	}
	return head;
}
```

###### 双向链表添加节点

将新数据元素添加到表头，只需要将该元素与表头元素建立双层逻辑关系即可。

换句话说，假设新元素节点为temp，表头节点为head，则需要做以下2步操作即可：

1. temp->next = head; head->prior = temp;
2. 将head移至temp，重新指向新的表头；
